# Contributing

Gripora is open source, and contributions -- code, documentation, and
testing -- are welcome. Gripora is stability-control firmware for RC cars,
forked from [WingFlight](https://github.com/WingFlight/wingflight-firmware)
(itself a fork of Rotorflight and Betaflight). The car conversion is in
progress, so some inherited code and naming still comes from the fixed-wing
firmware; see the [Developer Guide](developers.md) for what that means for a
change.

- **Documentation** (this site) lives in
  [gripora-project/gripora-docs](https://github.com/gripora-project/gripora-docs).
  Every page has an *Edit this page* link for quick fixes. User and developer
  documentation both live here, not in the firmware repository's `docs/`.
- **Firmware** lives in
  [gripora-project/gripora-firmware](https://github.com/gripora-project/gripora-firmware) --
  see [Building the Firmware](building-the-firmware.md).
- **Configurator** lives in
  [gripora-project/gripora-configurator](https://github.com/gripora-project/gripora-configurator).

See the [Developer Guide](developers.md) for the repositories and general
contribution guidance, [Code Guidelines and Testing](code-guidelines.md) and
[Coding Style](coding-style.md) for how to write the code, and the
[Technical Reference](tech/index.md) for the internals. Use the
[issue tracker](https://github.com/gripora-project/gripora-firmware/issues) to
discuss larger changes before starting.
