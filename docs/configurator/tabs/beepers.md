# Beepers

The Beepers tab configures which events (arming, low battery, failsafe,
receiver loss and so on) sound the controller's buzzer, as a warning while
driving and to find a car that stopped out of sight. The **BEEPER** mode
sounds it from a switch.

The buzzer hardware, wiring and the beeper sequences are described in
[Buzzer](../../reference/buzzer.md).
