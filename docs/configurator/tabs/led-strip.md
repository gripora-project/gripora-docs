# LED Strip

The LED Strip tab configures an addressable RGB LED strip connected to the
controller: the layout, the colors and what each LED shows (for example the
arm state or a warning). The tab only appears with the LED strip feature on
(Configuration tab). The **LEDLOW** mode turns the strip off from a switch.

LED types, wiring, the available functions and colors, and the CLI syntax are
described in the [LED Strip reference](../../reference/led-strip.md).
